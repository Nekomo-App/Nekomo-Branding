# Contributing brand assets

Before submitting a branding contribution:

1. Explain the intended use and asset type.
2. Provide an editable source file where practical (such as SVG or a layered design file).
3. Include a preview export such as PNG or WebP.
4. Include light/dark variants when relevant.
5. Confirm the work is original or its license permits the intended use.

Do not submit copied third-party logos, unlicensed fonts, or stock assets without appropriate rights. Clearly label proposals as drafts. Maintainers decide which submissions become approved official assets.
