# Logo assets

Place approved Nekomo logo files in this directory.

Suggested organization:
- `primary/` — primary approved logo
- `light/` — variants intended for dark backgrounds
- `dark/` — variants intended for light backgrounds
- `monochrome/` — approved single-color variants

Keep editable source files when available and include preview exports. Record file format, intended background, and approval status. Label unapproved concepts as drafts.
