# Color palette

This file is the source of truth for approved Nekomo brand colors once values are confirmed by project maintainers.

## Current status
No official color values are established in this document yet. Do not treat temporary colors in mockups as approved brand colors.

When adding an approved color, record:

| Field | Description |
|---|---|
| Name | Human-readable token name |
| HEX | Exact hexadecimal value |
| RGB | RGB equivalent |
| Usage | Intended UI or brand application |
| Contrast notes | Accessible foreground/background combinations |

Keep semantic UI colors (success, warning, error, information) distinct from core brand colors.
