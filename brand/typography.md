# Typography

Use typography that remains readable across mobile, TV, and web interfaces.

- Prefer a small, consistent type scale.
- Use clear hierarchy for titles, headings, body text, and captions.
- Avoid decorative typefaces for long-form reading.
- Ensure adequate line height and contrast.
- Verify that fonts support required characters and languages.

No official font family is recorded here yet. Add a font only after maintainers confirm its license, supported weights, and intended use. Prefer redistributable font licenses when storing font files in this repository.
